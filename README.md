Collegeboard has an awesome resource called SAT Suite Question Bank. It's a goldmine for people like me who are preparing for the exam. Yet, 
they only allow you to export questions via PDF (you can make your own PDF, it's awesome!) I prefer interactive ways of studying e.g while I'm 
solving my question, I like to know if it's right or wrong immediately or at the end of the quiz without manually having to check it. So I built 
this platform where the user must upload the quiz and the answer key, and they can receive feedback the moment they're done. A few features are:

- Question Sidebar: You can skip a question or return to a question
- It uses Gemini API to give you feedback on your mistakes
- It isolates questions from the others to display them on your screen

I would like to make this a free website/app
